Common questions

The useful details.

A few answers before we talk. Project-specific costs and timescales depend on the scope agreed at the start.

Can you build a simple one-page website?

Yes. A focused landing page is often the right starting point for a new venture, service or campaign. It can still include everything needed to explain the offer and generate enquiries.

Can the website grow later?

Yes. The initial structure can be planned so that new pages, services and features can be added as the organisation develops.

Will it work properly on mobile phones?

Yes. Responsive behaviour is built in from the start so the content and navigation remain clear across common screen sizes.

Do I need to provide all of the wording?

No. Existing notes, brochures and rough ideas can be shaped into clear website content. Where specific regulated or technical claims are needed, you remain responsible for confirming their accuracy.

Can you help improve an existing website?

Yes. That may involve a focused redesign, clearer content, improved navigation or rebuilding parts that no longer support what the organisation needs.
